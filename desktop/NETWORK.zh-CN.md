# 代理池

[English](NETWORK.md)

## 配置代理池

打开 **设置 → 代理池**，添加 HTTP、HTTPS、SOCKS5 或 SOCKS5h 节点。地址与用户名、密码分别填写，启用所需节点后保存。可指定 HTTP(S) 测试地址，对单个节点或全部启用节点发送 GET 请求，查看响应头延迟与结果；批量测试最多同时运行两个。

模型请求和 Python 目标访问分别设置策略，默认均跟随系统。

| 策略 | 模型请求 | Python 目标访问 |
| --- | --- | --- |
| 跟随系统 | 使用原生系统或环境代理 | 继承子进程环境 |
| 直连 | 明确绕过代理 | 清除代理变量，设置 urllib 直连 |
| 固定节点 | 使用一个启用节点 | 使用一个启用的 HTTP(S) 节点 |
| 失败切换 | 连接失败或代理认证拒绝时依次尝试其他节点 | 不提供，避免重放脚本 |
| 轮询 | 每个请求轮换首选节点，连接失败时尝试其余候选节点 | 每次执行轮换 HTTP(S) 节点 |

每个模型请求保留开始时的候选列表。失败节点冷却 30 秒，固定节点可立即手动重试；没有可用节点时返回错误，不自动降级为直连。流式响应开始后不重发请求。模型返回的 HTTP 错误交给 Goal 处理；发送后的超时也不会自动重发请求体。

Python 代理变量只作用于当前子进程，并显式配置 urllib。内置 URL 初筛以及遵循环境代理的客户端会使用该路由；自建传输或原始套接字可以绕过，代理设置不构成网络沙箱。SOCKS 节点用于模型请求，Python 目标访问目前需要 HTTP(S) 代理。更新器、可选的 Sentry 诊断及外部独立运行的 MCP 客户端保留各自的网络配置。

保存后对后续请求和执行生效，已经开始的流式请求、子进程保持原路由。浏览器预览可编辑配置，测试代理与强制路由需要桌面应用；预览的系统模式使用浏览器网络设置。

## 数据与错误

节点与认证保存在本机 WebView 存储中，尚未接入系统钥匙串加密。配置不写入 Goal 提示词、报告或工作区记录。子进程输出会脱敏已配置的代理认证信息；自定义脚本应避免打印敏感环境变量。节点测试仅记录状态与延迟。网络故障使用 `PROXY_*` 和 `NETWORK_*` 错误码，见[错误分类](ERROR_CODES.md)。

后台性能异常提醒与可选的远程诊断分别在 **设置 → 诊断** 中配置，详见[诊断说明](DIAGNOSTICS.zh-CN.md)。返回[桌面使用指南](README.zh-CN.md)。
