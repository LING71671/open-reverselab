# Scripts

分析脚本和自动化工具。

## 目录

| 目录 | 用途 |
|---|---|
| `_shared/` | 跨领域脚本 (crypto, Ghidra) |
| `android/` | Android 分析脚本 (Frida, repack) |
| `benchmark/` | TSec Benchmark 平台接入 (tsec-benchmark SDK 驱动 + solver 适配) |
| `ctf-website/` | Web CTF 脚本 (probe, CVE pipeline) |
| `misc/` | 通用脚本 (healthcheck, tool management) |
| `windows/` | Windows 分析脚本 (debug, Frida, Procmon) |
